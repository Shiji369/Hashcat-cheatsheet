# Hashcat Hash Modes Reference

A comprehensive reference guide for **Hashcat Hash Modes**, including common hash algorithms, Hashcat mode IDs, and example hash formats. This repository serves as a quick reference for cybersecurity students, penetration testers, and digital forensics practitioners.

---

## Overview

Hashcat identifies each supported hash algorithm using a unique **Hash Mode ID**. Selecting the correct hash mode is essential for successful password recovery and security assessments.

This reference includes:

- Hash Mode IDs
- Hash Algorithm Names
- Example Hash Formats
- Common Password Hashes
- Authentication Protocol Hashes
- Database Hashes
- Operating System Hashes
- Archive & Document Encryption Hashes
